# Security-Onion

## Security Onion - Network Security Monitoring (NSM) & SIEM

### 🔍 Summary & Evidence
- **Deployment & Configuration:** Configured a Security Onion standalone/sensor node to monitor internal network traffic and process telemetry.
- **Traffic Analysis & PCAP Replay:** Replayed malicious traffic captures (PCAPs) using `tcpreplay` to evaluate detection rules and alert generation across the stack.
- **Alert Triage in Security Onion Console (SOC):** Analyzed incoming alerts generated by **Suricata** (NIDS) and **Zeek** (NSM), identifying suspicious patterns such as port scanning, privilege escalation attempts, and C2 communications.
- **Log Management & Threat Hunting:** Utilized **OpenSearch / Kibana** dashboards to query Sysmon events, endpoint telemetry, and network logs to construct attack timelines.

### 🛡️ Detection & Investigation Findings

| Incident / Alert Type | Tool / Engine | Key Artifacts | Recommended Action |
| :--- | :---: | :--- | :--- |
| **NIDS Alert: EternalBlue / SMB Exploit** | Suricata | Signature match on Port 445, suspicious payload patterns | Isolate target host, apply MS17-010 patch, and block SMB at perimeter. |
| **Anomalous Outbound Traffic** | Zeek (`conn.log` / `dns.log`) | High volume of DNS requests to suspicious TLDs | Quarantine endpoint, check for active C2 beacons, update DNS sinkhole. |
| **Suspicious Process Execution** | Sysmon / Wazuh | `powershell.exe` executing encoded commands | Kill process, collect memory dump for analysis, reset affected user credentials. |

### 🧱 Hardening & Tuning Recommendations
1. **Rule Fine-Tuning:** Disable noisy or irrelevant NIDS signatures to reduce false positives and analyst alert fatigue.
2. **SPAN/TAP Optimization:** Ensure Network TAP or SPAN ports mirror all critical segment traffic to avoid blind spots in NSM coverage.
3. **Log Retention & Backup:** Configure automated retention policies and remote log archiving for compliance and long-term threat hunting.
